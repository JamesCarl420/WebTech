HTML TEXT FORMATTING

1. Bold Text - <b>

The <b> tag makes text appear bold.

2. Strong Text - <strong>

The <strong> tag indicates that the text strong importance.

3. Italic Text - <i>

The <i> tag displays text in italic style.

4. Emphasized Text - <em>

The <em> tag emphasizes text.

5. Underlined Text - <u>

The <u> tag underlines text.

6. Highlighted Text - <mark>

The <mark> tag highlights text.

7. Small Text - <small>

The <small> tag displays smaller text.

8. Deleted Text - <del>

The <del> tag represents deleted text.

9. Inserted Text - <ins>

The <ins> tag represents inserted text.

10. Subscript - <sub>

The <sub> tag displays text below the normal line.

11. Superscript - <sup>

The <sup> tag displays text above the normal line.
