Learning Emmet

What is Emmet?

Emmet is a set of abbreviations that expands into HTML and CSS code in supported editors.

It can create nested elements, classes, IDs, attributes, and repeated elements quickly.

Quick Tips

  • Type an abbreviation.
  • Press Tab or select the Emmet suggestion.
  • Check the generated structure.
  • Use semantic elements where appropriate.
